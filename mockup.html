Install on your phone for quick, one-tap access

Add to Home Screen

Install Read the Heat for one-tap access, no app store needed.

  1. Safari: tap the Share button ↗, then Add to Home Screen, then Add.
  2. Chrome: tap the Share icon beside the address bar, then Add to Home Screen.
  3. Firefox: open the menu, tap Share, then Add to Home Screen.

The icon will appear on your home screen under Read the Heat.

What you're seeing

Layout:

The tool switches to its phone layout at 600 px wide or narrower. A tablet held upright gets the phone layout; turned sideways it gets the wider layout.

It's the live tool

Everything inside the frame is the real app — changes to any page file show up here on reload. Tap, scroll, and fill in fields as on a real device.

The frame loads the file directly from the repo, so all calculators and cross-page links work normally.
